# Contract: Transactional Emails

**Feature**: `001-platform-foundation` · Code: `apps/web/src/server/email/` · Implements FR-004, FR-005,
FR-010, FR-020, FR-023, FR-038

## 1. Sending

```ts
// apps/web/src/server/email/send.ts
export type EmailMessage = { to: string; subject: string; text: string; html: string };
export function sendEmail(message: EmailMessage): Promise<void>;   // throws on transport failure
```

- Transport is chosen by `EMAIL_TRANSPORT` (`transport.ts`):
  - `smtp` — Nodemailer SMTP transport from the `SMTP_*` variables; `from` = `EMAIL_FROM`.
  - `capture` — nothing is sent. Each message is written to
    `<EMAIL_CAPTURE_DIR>/<epoch-ms>-<8 random hex>.json` as
    `{ "to", "from", "subject", "text", "html", "createdAt" }` (UTF-8), and one line is logged:
    `log.info('email.captured', { template })`. In `APP_ENV=development` the first URL in `text` is also
    printed to the terminal so a developer can click it.
- Callers log `email.sent` / `email.failed` with the template name only (never the address or content).

## 2. Template rules

Each template is a pure function in `apps/web/src/server/email/templates/<name>.ts` returning
`{ subject, text, html }`, built with the shared `layout.ts`.

- **Bilingual, Arabic first**: the body contains an Arabic block (`<div dir="rtl" lang="ar">`) followed by a
  divider and an English block (`<div dir="ltr" lang="en">`). `text` has the same content in plain text,
  Arabic first. Subjects are `"<Arabic> | <English>"`.
- All interpolated values are HTML-escaped in `html`. URLs appear as a button-style link **and** as visible
  text (and on their own line in `text`).
- Inline CSS only; no images, no external resources, no tracking. System font stack.
- Every email ends with a line saying it was sent by Masari on behalf of the college (name in the matching
  language when known) and that it can be ignored if unexpected.
- Unit tests per template: both languages present and Arabic first; the URL appears in `text` and `html`;
  a value containing `<script>` is escaped; subject format.

## 3. Templates

| Template (file) | Sent by | To | Inputs | Subject (ar \| en) | Content |
|---|---|---|---|---|---|
| `verify-email.ts` | `registerStudentAction`, `resendVerificationAction` (through the auth library's `sendVerificationEmail` hook) | registrant | `name`, `url` | `تأكيد بريدك الإلكتروني في مساري \| Confirm your email for Masari` | Greeting, confirm button/link, valid for 24 hours |
| `account-exists.ts` | `registerStudentAction` (existing account) | account owner | `signInUrl`, `resetUrl` | `لديك حساب بالفعل في مساري \| You already have a Masari account` | Someone tried to register with this email; sign in or reset the password; ignore if it was not you |
| `invitation-pending.ts` | `registerStudentAction` (pending invitation) | invitee | `collegeNameAr`, `collegeNameEn` | `لديك دعوة للانضمام إلى مساري \| You have an invitation to join Masari` | You already have an invitation from the college; use the link in that email or ask the administration to send a new one. **No link to accept** (the token is not recoverable) |
| `reset-password.ts` | `requestPasswordResetAction` (through the auth library's `sendResetPassword` hook) | account owner | `name`, `url` | `إعادة تعيين كلمة المرور في مساري \| Reset your Masari password` | Reset button/link, valid for 1 hour, ignore if not requested |
| `invitation.ts` | `createInvitationAction` | invitee | `collegeNameAr`, `collegeNameEn`, `role`, `url` | `دعوة للانضمام إلى {collegeNameAr} على مساري \| Invitation to join {collegeNameEn} on Masari` | You are invited as «role label» (Arabic and English labels from `permissions.md` §1); accept button/link; valid for 7 days |

URL forms (all absolute, built from `APP_URL`):

| Purpose | URL |
|---|---|
| Confirmation | generated by the auth library → `…/api/auth/verify-email?token=…&callbackURL=/{locale}/email-verified` |
| Reset | generated by the auth library → `…/api/auth/reset-password/{token}?callbackURL=…/{locale}/reset-password` |
| Sign in / forgot password (account-exists) | `{APP_URL}/ar/sign-in`, `{APP_URL}/ar/forgot-password` |
| Invitation | `{APP_URL}/ar/invite/{token}` |

/** Polls the capture directory (up to 10 s) for the newest message to `to` whose subject contains
